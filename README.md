🗄️ SQL Data Analytics – MySQL Project

A practical SQL Data Analytics project built using MySQL to demonstrate database creation, data management, querying, and analytical operations using real-world business-style datasets.

This project covers the complete SQL workflow, including database and table creation, DDL, DML, primary and foreign keys, data manipulation, constraints, transactions, and CRUD operations. The database contains interconnected tables for departments, employees, customers, orders, products, and order items.

🔍 Project Features
🏗️ Database & Table Creation – Created a structured relational database with multiple interconnected tables.

🔑 Primary & Foreign Keys – Implemented relationships and referential integrity between tables.

🛠️ DDL Operations – Practiced CREATE, ALTER, DROP, TRUNCATE, column modifications, and table management.

✏️ DML Operations – Used INSERT, UPDATE, and DELETE to manage records.

👨‍💼 Employee Analysis – Managed employee details, departments, salaries, managers, and hiring information.

👥 Customer Management – Stored and updated customer information, cities, and signup dates.

🛒 Order & Product Management – Worked with orders, products, transactions, quantities, prices, and order status.

🔗 Relational Data Handling – Used foreign-key relationships to maintain data consistency.

📅 Date Functions – Worked with dates and CURRENT_DATE for dynamic date insertion.

🔄 Transactions – Practiced START TRANSACTION, COMMIT, and ROLLBACK for safe data operations.

🧹 Data Cleaning – Handled NULL values and duplicate records.
